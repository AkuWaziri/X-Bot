# X-Bot

Telegram-controlled X activity monitor and reply assistant.

## Phase 1
- Telegram bot foundation
- Configuration and secrets structure
- GitHub Actions scheduler
- Safe dry-run mode

## Security
Secrets must be stored in GitHub Actions Secrets and never committed to the repository.

## Planned
- Monitored account whitelist
- New-post detection
- Reply-opportunity scoring
- Dynamic short reply generation
- Telegram approval workflow
- Pluggable low-cost X data provider
